# Gv — 영상 동시재생기 v15 (Media Board)

v12(Gv) + v5.15(videoboard Ultra Masterpiece) + GvUX2 대화기록의 요구사항을 하나로 합친 완전판입니다.

## 실행
`run.bat` 더블클릭 → 브라우저가 `http://localhost:8000` 으로 열립니다. (Python 3 표준 라이브러리만 사용, Flask 불필요)
- 세션에 영상까지 저장하는 Cache API 는 `file://` 에서 동작하지 않아서 반드시 run.bat 으로 여세요.
- 창을 닫으면 서버가 종료됩니다.

## 조작
| 동작 | 방법 |
|---|---|
| 카드 선택 | 첫 클릭 (선택한 카드에만 재생바·삭제 버튼 표시) |
| 재생/정지 | 더블클릭 / Space |
| 위치 이동 | 숫자·넘패드 1~9 = 10~90% / ← → = 스킵(초 조절 가능) |
| A-B 구간 반복 | A, B 키 또는 재생바의 A/B/⟲ |
| 음소거 / 전체화면 | M / F |
| 카드 크기 (재생 중에도) | 선택 카드 오른쪽 아래 모서리 드래그 / Ctrl+휠 / + − 키 (0.5열 단위) |
| 크게 보기 ↔ 원래 크기 | Z 또는 재생바의 ⤢ 버튼 / 0 = 1열로 |
| 선택 해제 · 패널 닫기 | Esc |
| ZIP 전체 동기 스크롤 | 오른쪽 막대 드래그 / Alt+휠 |

선택한 카드나 키보드 조작은 선택된 카드에만 적용되고, 선택이 없으면 전체 영상에 적용됩니다.

## 기능
- 영상 / GIF / WebP / 이미지 / ZIP 다중 추가 (파일 선택 · 드래그&드롭 · URL)
- 기본 음소거 · 반복재생 · 추가 즉시 재생
- 실제 영상 비율 기반 Pinterest 방식 masonry 1~8열, 1열은 화면 폭의 70%, 500MB 이상 영상은 기본 2열, 촘촘한 기본 간격(4px)
- 드래그로 위치 변경, 재생 중에도 카드 크기를 0.5열 단위로 키우고 줄이기(모서리 드래그·Ctrl+휠·+/−·크게 보기), 다른 카드가 부드럽게 밀려남
- YouTube 스타일 재생바: 진행·버퍼·스크럽·재생/정지·음소거·A-B·배속·반복·PiP·전체화면·원본 PNG 캡쳐·채우기·카드별 필터
- 재생바와 버튼 크기는 카드 크기에 비례
- ZIP 사진 모드: 압축 해제 없이 미리보기, ZIP 하나가 세로 컬럼 하나, 2~6열(자동/고정), 컬럼별 스크롤 + 페이지 스크롤 + 전체 동기 스크롤(동일 속도 / 비율 모드), 중첩 폴더·ZIP 안의 ZIP 지원
- 세션(세이브 파일): 레이아웃·설정·카드 상태 저장/복원, 영상은 Cache API 에 보관해 파일 재선택 없이 복원, JSON 내보내기/가져오기, 마지막 종료 상태 자동 저장
- 프라이빗 모드: 영상 캐시·자동 저장·세션 기록을 남기지 않음, 남은 기록 전부 지우기 (영상 파일은 어떤 경우에도 인터넷으로 전송되지 않음 — URL 추가 기능 제외)
- 앱 설치(PWA): https 주소에서 크롬 주소창의 설치 아이콘 → 바탕화면 앱, 오프라인 실행
- 디자인: 와인빛 오로라 배경, 유리 질감 상단 바·패널, Pretendard 글꼴, 새 아이콘·로고
- 설정 프로파일, 다크/라이트, 포인트 색상(RGB), 나이트 모드, 블루라이트 차단, 필터 12종 + 강도, 카드 간격, 화면 패딩, 확대/축소, 글꼴·UI 크기
- 성능: 동시 재생 상한 + 자동 조절, 화면 밖 자동 일시정지, Lazy loading(디코더·GIF 메모리 해제), 저전력 모드, FPS·해상도(UHD) 표시, 해상도 강제(캔버스 렌더, 실험)
