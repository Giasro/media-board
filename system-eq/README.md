# 시스템 EQ (컴퓨터 전체 소리 이퀄라이저)

윈도우 전체 소리(유튜브, 게임, 디스코드, 음악 앱 등)에 EQ를 거는 방법이에요.
**Equalizer APO**(무료, 지연 없음)를 설치하고, 이 폴더의 프리셋으로 취향 EQ를 바로 바꿔 쓸 수 있어요.

## 1. 설치 (한 번만)
1. 공식 배포처에서 Equalizer APO를 받아 설치해요: https://sourceforge.net/projects/equalizerapo/
2. 설치 마지막에 **Configurator**가 뜨면, EQ를 적용할 **출력 장치(스피커/헤드폰)** 에 체크해요.
   - 블루투스 장치는 목록에 안 보이거나 안 먹을 수 있어요. 이어폰은 유선/USB 기준으로 확인해 보세요.
3. **컴퓨터를 재부팅**해요.

## 2. 프리셋 바꾸기
- `프리셋 선택.bat`을 실행하면 관리자 권한을 물어보고, 번호를 고르면 바로 적용돼요(재부팅 불필요).
- 프리셋은 `presets` 폴더의 txt 파일이에요. 복사해서 숫자 값을 고치면 나만의 프리셋이 돼요.
- 소리가 너무 크거나 찌그러지면 해당 파일의 `Preamp:` 값을 더 작게(예: -7 dB) 바꿔요.

## 3. 프리셋 문법 (직접 고칠 때)
```
Preamp: -5 dB                                   # 전체 볼륨을 먼저 낮춰서 찌그러짐 방지
Filter: ON PK  Fc 1000 Hz Gain 3 dB Q 1.0       # 종 모양 (특정 대역을 올리거나 내림)
Filter: ON LSC Fc 100 Hz Gain 4 dB             # 저음 셸프
Filter: ON HSC Fc 8000 Hz Gain 3 dB            # 고음 셸프
Filter: ON HP  Fc 70 Hz                         # 로우컷
Filter: ON LP  Fc 16000 Hz                      # 하이컷
```

## 4. 화면으로 조절하고 싶다면
**Peace**(Equalizer APO용 무료 GUI)를 같이 설치하면 슬라이더로 EQ를 만질 수 있어요: https://sourceforge.net/projects/peace-equalizer-apo-extension/
(Peace는 자체 설정 파일을 쓰니, 쓸 때는 이 폴더의 프리셋과 번갈아 쓰기보다 한쪽만 쓰는 게 편해요.)

## 5. 원래대로 되돌리기
`01_끄기(원본)` 프리셋을 적용하면 EQ가 꺼져요. 완전히 제거하려면 Equalizer APO를 프로그램 삭제하면 돼요.

## 변화가 약하게 느껴질 때
- 프리셋의 `Gain` 숫자를 키우면 효과가 커져요 (예: 8 dB → 12 dB). 올린 만큼 `Preamp:` 는 더 내려야(더 작은 음수) 소리가 안 찌그러져요.
- `Preamp` 를 낮추면 전체 볼륨이 작아져서 처음엔 효과가 덜 느껴질 수 있어요. 윈도우 볼륨을 올려서 비교해 보세요.
- 헤드셋 자체가 낼 수 있는 저음에는 한계가 있어요 (특히 USB 게이밍 헤드셋). 08번(초강력 베이스)을 쓰면 확실히 차이가 나요.

## 볼륨이 원본보다 작을 때
- 메뉴에서 `+` 를 누르면 Preamp 가 1dB 씩 올라가요. 원본과 비슷한 크기가 될 때까지 올리고, 소리가 지직거리면 `-` 로 한 칸 내리세요.

## 베이스가 오히려 약하거나 먹먹할 때
- 같은 볼륨에서 `01_끄기`와 비교하세요. `Preamp` 로 전체가 작아진 상태라 비교할 땐 윈도우 볼륨을 3~5칸 올려야 해요.
- 100~300Hz 를 많이 올리면 소리가 탁하고 막혀요. 저음 셸프는 50~70Hz 에 걸고, 250Hz 근처는 살짝 내리면 깔끔해요.
- 소리가 지직거리면 `Preamp` 를 더 내리세요(예: -5 → -7 dB).
